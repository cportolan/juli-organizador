# Organizador Juli

## Descripción
Proyecto generado con Next.js, utilizando JSX y Vanilla CSS (sin librerías de estilos como Tailwind).

## Stack
- Next.js (App Router)
- React
- JavaScript (JSX)
- CSS Vanilla (CSS Modules + globals.css)

## Scripts
- `npm run dev` — levanta el servidor de desarrollo
- `npm run build` — genera el build de producción
- `npm run start` — corre el build de producción
- `npm run lint` — corre el linter

## Estructura
- `app/layout.js` — layout raíz
- `app/page.js` — página principal
- `app/globals.css` — estilos globales
- `app/page.module.css` — estilos locales de la página principal
